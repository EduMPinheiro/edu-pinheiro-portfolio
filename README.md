# Edu Pinheiro — Web Designer & Developer

Personal portfolio for Edu Pinheiro, a freelance web designer and developer.

The site presents selected client, concept, and independent projects in a bilingual React + Vite experience with an editorial cyberpunk visual direction.

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```
